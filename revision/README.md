# Révision de la base

Application web installable pour réviser les fiches du dossier BASE (OneDrive).

- Les fiches Word (.docx) sont importées depuis l'appareil ; elles sont lues et stockées **uniquement dans le navigateur** (IndexedDB). Aucun contenu de la base n'est publié dans ce dépôt.
- Formats : chiffres clés (QCM), vrai ou faux, restitution de sections, lecture et recherche.
- Répétition espacée (boîtes de Leitner : 0, 1, 3, 7, 16, 35, 80 jours).
- Fonctionne hors connexion après la première visite. Sauvegarde/restauration JSON pour passer d'un appareil à l'autre.

Adresse : https://yvanov40.github.io/public/revision/
